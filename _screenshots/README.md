# 📸 Jmart — لقطات شاشة النظام

## الملفات الجاهزة للمشاركة

| الملف | الحجم | الاستخدام |
|---|---|---|
| **`gallery.html`** ⭐ | 8.2 MB | **ملف واحد قائم بذاته** — افتحه في أي متصفح أو أرسله بالإيميل. كل اللقطات مدمجة كـbase64. |
| **`img/`** | 6.2 MB | 29 لقطة PNG منفصلة لو احتجتها للعرض الفردي. |

## كيف تشاركه

### 📧 إيميل / واتساب
أرسل `gallery.html` كملف مرفق. مَن يستلمه يفتحه بنقرة وحدة في أي متصفح، حتى بدون إنترنت.

### 📄 PDF
1. افتح `gallery.html` في Chrome
2. اضغط `Ctrl+P`
3. Layout: Landscape · Margins: None · Background graphics: ✓
4. Save as PDF

### 🖼️ صور فردية
كل صورة موجودة في `img/`:
- **mobile-*.png** — 7 شاشات تطبيق الموبايل (390×844)
- **portal-*.png** — 10 شاشات بوابة المزرعة/المشتري (1280×800)
- **admin-*.png** — 12 شاشة لوحة الإدارة (1440×900)

## إعادة التوليد

لو حدّثت التصميم وأردت لقطات جديدة:

```powershell
# تأكد من أن السيرفرات شغّالة (API:3000, Admin:3002, Portal:3003, Mobile:8081)
cd C:\Jmart\_screenshots
node capture.js          # يلتقط 29 PNG في img/
node build-gallery.js    # يبني gallery.html بكل اللقطات مدمجة
```

## المتطلبات
- **Chrome** مثبت في `C:\Program Files\Google\Chrome\Application\chrome.exe`
- **Node.js** (للسكربتات فقط — مَن يستلم الـHTML لا يحتاج Node)
- **puppeteer-core** (مثبت تلقائياً في `node_modules/`)
